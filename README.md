# SafeMind AI - IEEE ACSS Ideathon 2025

## 🎯 Problem
Dataset poisoning and AI hallucinations threaten AI reliability in healthcare, finance, and defense.

## 🔧 Solution
SafeMind AI uses a 3-stage pipeline:
- **Detection:** Isolation Forest and embedding similarity to spot poisoned data.
- **Comparison:** LLM confidence scores and knowledge base verification.
- **Correction:** RAG pipelines and statistical refinement to correct data.

## 🛠️ Tech Stack
- Python, scikit-learn, PyTorch, LangChain, OpenAI Embeddings

## 📊 Results
- 96.8% detection accuracy with Isolation Forest
- Scalable for large datasets (O(n log n))
